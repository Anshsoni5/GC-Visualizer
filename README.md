# 🧠 GC Visualizer — Garbage Collection Simulator

An interactive web-based visualization tool to understand how different garbage collection algorithms work in memory management.

## 🚀 Features

- 🔹 Reference Counting Simulation
- 🔹 Mark-and-Sweep Algorithm (Step-by-step)
- 🔹 Generational Garbage Collection
- 🔹 Interactive UI with drag-and-drop nodes
- 🔹 Real-time memory graph visualization
- 🔹 Logs and step indicators for better understanding

## 🛠️ Tech Stack

- HTML5
- CSS3 (Dark UI Design)
- JavaScript (Core Logic & Animation)

## 📚 Algorithms Covered

1. Reference Counting
2. Mark and Sweep
3. Generational Garbage Collection

## 🎯 Purpose

This project is designed for:
- Students learning Operating Systems
- Understanding memory management visually
- Demonstrating GC algorithms in presentations

## 💡 How to Run

1. Download or clone the repo
2. Open `gc-visualizer.html` in your browser
